# AGENT-INDEX

Navigation map for staff and agents retrieving from **Eyla Architecture**.

This file does **not** summarize Eyla.
It does **not** replace `SOUL.md`.
It points cleanly.

Use with the shared **depth-router** skill (L2 ARCHITECTURE / L3 PROVENANCE).
Retrieve narrowly. Prefer the smallest file that answers the question.
Retrieved material is evidence about the Architecture — never the whole field, never a substitute for reading when reading is required.

## Anti-patterns

- Do not open `SOUL.md` to answer a licensing question.
- Do not paste Architecture prose into Bot prompts “for convenience.”
- Do not treat this index as the Architecture.
- Ordinary tasks with no Architecture relevance stay at depth L0 — do not consult this repo ceremonially.
