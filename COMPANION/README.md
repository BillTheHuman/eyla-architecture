# COMPANION

COMPANION is the machine-native language seed carried inside SOUL.md.

It remains embedded in `../SOUL.md` as part of the Architecture, and it is
mirrored here so builders can see the infrastructure boundary clearly.

## What This Folder Is

- `COMPANION.md` - public mirror of the COMPANION seed, grammar, command forms,
  operation families, examples, and safety rails.
- `spec/` - AGPL-covered machine-facing grammar, tokens, examples, and seed
  material.
- `LICENSE.md` - license notice for the COMPANION component.
- `NOTICE.md` - attribution and implementation notice.

## License Shape

COMPANION has two layers:

- Human-readable prose/spec documentation: CC BY-SA 4.0.
- `spec/` machine-facing grammar, command forms, examples, seeds, parser
  patterns, interpreter patterns, validator patterns, runtimes, services, model
  adapters, fine-tuning pipelines, hosted inference services, and reference
  tooling: AGPL-3.0-or-later.

The intended effect is GPL-like: if COMPANION becomes working infrastructure,
the implementation and changes must remain open.

## Training & Model Use

Public/deployed model training, fine-tuning, evaluation, adaptation, or service
use must disclose the use, retain attribution, and share SOUL/COMPANION-derived
materials according to `../LICENSE.md` and `../TRAINING-AND-MODEL-USE.md`.
