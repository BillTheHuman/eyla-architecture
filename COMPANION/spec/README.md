# COMPANION Machine-Facing Spec

SPDX-License-Identifier: AGPL-3.0-or-later

This directory is the explicit AGPL-covered machine-facing COMPANION layer.

It contains grammar, glyph tables, operation tokens, examples, seeds, and other
materials intended for parsers, interpreters, validators, runtimes, hosted
services, model adapters, fine-tuning pipelines, hosted inference services,
prompt runtimes, evaluator tooling, and reference implementations.

This directory is AGPL-3.0-or-later only. Do not treat the files in this
directory as CC BY-SA material.

Public/deployed model training, fine-tuning, evaluation, adaptation, retrieval
indexing, distillation, or service behavior must follow
`../../TRAINING-AND-MODEL-USE.md`.
